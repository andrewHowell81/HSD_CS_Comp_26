# HSD_CS_Comp_26
This is an example repository for the Computer Science Competition in High School Design 2026. Below are in depth explanations of what your project submission for HSD should look like.

## README.md
Your github repository should include a README.md that explains your application. This should include:
- Project overview
- Setup instructions
- Usage guide
- Feature list
- Team contributions

## Documentation
All code must be well documented. This means:
- Comments before functions to describe purpose
- Comments at the top of each file to describe purpose
- Comments to cite usage of AI, or other sources

## Codebase
Includes all files created by your team to run this application.

## Where should I start?
If you have never done web development before, check out some resources below to get started.

### VS Code
VS code is a standard IDE (integrated development environment). Software engineers use VS Code to edit their code files. Think of it like
a Microsoft Word, but for coding! Follow this download link to get started.

https://code.visualstudio.com/download

### HTML and CSS
HTML and CSS are two programming languages that are foundational to web developemnt. Using these two languages you can get started making websites.
I would recommend understanding the basics of HTML and CSS before you get any further into development. 

Here is a great tutorial to get started: https://www.youtube.com/watch?v=HGTJBPNC-Gw
